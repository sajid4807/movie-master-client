# 🎬 Movie Master

## 📖 Project Overview
Movie Master is a responsive movie management web application that allows users to explore, save, and manage movies.

## 🌐 Live Demo
🔗 https://movie-master-216f7.web.app

## 🖼️ Screenshot
<img src="https://i.ibb.co/zHmfdqG4/movies2.png" alt="Movie Master Screenshot" />

## ✨ Core Features
- User authentication with Firebase
- Add, edit, and delete movies
- Responsive UI with Tailwind CSS
- Protected routes

## 🧰 Technologies Used
### Frontend
- React.js
- Tailwind CSS
- DaisyUI

### Backend
- Node.js
- Express.js
- MongoDB

### Authentication
- Firebase Auth

## 📦 Dependencies
- react
- react-router
- firebase
- axios
